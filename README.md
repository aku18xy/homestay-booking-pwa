# Sistem Tempahan Homestay (Custom PWA)

Sistem tempahan homestay moden berasaskan web (Progressive Web App) dengan integrasi kalendar masa nyata, kiraan harga dinamik, pembayaran terus DuitNow QR, dan notifikasi tempahan terus ke WhatsApp pemilik.

---

## 🚀 Ciri-Ciri Utama
- **1 Domain .MY & Cloud Hosting**: Identiti profesional & akses pantas dengan sijil keselamatan SSL percuma.
- **Progressive Web App (PWA)**: Boleh dipasang (*Add to Home Screen*) pada peranti Android & iOS tanpa perlu muat turun dari app store.
- **Live Calendar (Anti Double-Booking)**: Kalendar masa nyata dengan mekanisme kunci tarikh automatik bagi mengelakkan pertindihan tempahan.
- **Enjin Harga Automatik**: Kiraan serta-merta mengikut bilangan malam, kadar hari biasa (weekday), hujung minggu (weekend), dan musim puncak/cuti umum.
- **Tanpa Pendaftaran Akaun**: Tetamu menempah dengan pantas hanya mengisi Nama & Nombor WhatsApp tanpa halangan login.
- **Bayaran Terus DuitNow QR**: Duit masuk terus ke akaun pemilik homestay tanpa potongan komisen pihak ketiga berserta fungsi muat naik slip bukti bayaran.
- **Integrasi WhatsApp**: Notifikasi dan pautan semakan tempahan dihantar secara berstruktur ke WhatsApp pemilik homestay.
- **Dashboard Pengurusan Pemilik**: Kawal status tempahan (Luluskan / Tolak), semak resit pembayaran bersaiz penuh, dan kunci tarikh secara manual.
- **Landing Page Lengkap**: Galeri gambar resolusi tinggi, kemudahan (amenities), lokasi & panduan arah (Waze/Google Maps), testimoni tetamu, dan FAQ.

---

## 🛠️ Stack Teknologi
- **Frontend**: Next.js 14 / React, Tailwind CSS, Lucide Icons, Shadcn UI
- **Backend / API**: Next.js Serverless Route Handlers
- **Pangkalan Data & Storage**: Supabase (PostgreSQL + S3 Storage untuk slip bayaran)
- **PWA**: Service Worker & Web App Manifest
- **Hosting**: Vercel / Cloudflare
